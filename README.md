# Todoist widget

A resizable home-screen widget for Todoist. Each placed widget shows one **project**, **saved
filter**, or **custom filter query**: place two (e.g. Work and Personal) side by side at 2×2.

- Sorted **most overdue first, then priority** (or priority first, per widget).
- Row: priority circle (tap = complete) · task (tap = open in Todoist) · due: `3d` / `2w` overdue in
  red, `Today` / `2:30pm` green, `Tmrw` orange, `Fri` purple, `Nov 12`; `↻` = recurring.
- Header: title (tap = full panel), overdue count (red), total, ↑ update symbol, refresh, **+** (Todoist quick add).
- The list scrolls; capped at 60 rows with a "+N more" row.

Sizes: **1×1** overdue (or total) count · **2×1 / 2×2** one-line list · **3×1** + project names ·
**4×1** two columns · **2×3** two-line rows · **3×2+** two-line rows (project · @labels · ⚑deadline ·
description) + Todoist icon + "updated 5m" · **3×3+** everything (also the expand panel).

## Setup
1. Todoist → Settings → Integrations → Developer → copy your API token.
2. Open **Todoist Widget** → paste it → **Save token**.
3. Place the widget, tap it ("Tap to choose a project or filter"), pick one, **Save widget**.
   Long-press the widget → settings to change it later.

Permissions: internet only. The token stays on the phone and is only sent to api.todoist.com.

## Refresh
Every ~15 min in the background (JobScheduler), the refresh button, ~25 s and ~2 min after you open
Todoist from the widget, after completing a task, and when the setup screen opens.

## Updating
Via **Widget Updater** (jonomf/widget-updater): the widget shows a small ↑ when a new build is out;
tap it. Fallback: setup screen → **Get the latest build in the browser**.

## How it works
- `Api` — Todoist API v1: `/sync` (projects, saved filters, name), `/tasks/filter?query=`,
  `/tasks?project_id=`, `/tasks/{id}/close`.
- `Sync` — one background thread: fetches every widget's tasks; completing hides the task everywhere
  at once, closes it, then refetches. `SyncJob` = periodic + "soon" jobs.
- `Store` — token, per-widget `Config`, cached tasks (SharedPreferences).
- `WidgetRenderer` — one layout per size (`Kind`); lists use `RemoteCollectionItems` (no service).
- `TapActivity` — invisible; handles list taps (open / complete) and opening Todoist (`todoist://`
  URLs, falling back to the web, then the app).
- `PanelActivity` — expand panel; draws the XL layout with the same code.
- Layouts are generated by `tools/gen_layouts.py` (edit there, then run it).

Every push to `main` builds a release tagged `build-N` (GitHub Actions); N is the versionCode.
